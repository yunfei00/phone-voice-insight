# Phone Voice Insight V0.1.0 项目交付说明

## 1. 交付范围

V0.1.0 是手机用户声音平台初期可运行版本，覆盖产品与来源管理、公开数据采集、原始帖子树、确定性治理、AI 复核与结构化分析、驾驶舱、洞察报告和运行监控。

本次不新增 AI 助手，不包含京东登录墙绕过、地域猜测、真实故障率推断或未经授权的大批量 AI 调用。

## 2. 发布基线

- 仓库：`yunfei00/phone-voice-insight`
- 基线：`4a70143`
- 工作分支：`release/v0.1.0-acceptance`
- PR：<https://github.com/yunfei00/phone-voice-insight/pull/12>
- 版本：后端、前端均为 `0.1.0`

## 3. 本轮关键改进

1. 修复一键全量治理在 `source_id=null` 时返回 400 的 P0 缺陷。
2. 对治理、AI 复核和结构化分析的可选 ID 统一支持缺失或 null。
3. 增加任务投递失败、单条异常、部分成功和失败记录精确重试测试。
4. 明确前端请求契约，清空来源时发送 null 表示“不限制来源”。
5. 升级 Axios、Vue、Vite、Vitest 及相关锁定依赖，`npm audit` 为 0。
6. 完成隔离 Docker Compose 构建、迁移、队列执行和重启恢复验收。

## 4. 交付结论

核心发布门禁已通过。荣耀在线复验、真实付费 AI 和新截图受外部限制，按状态规范记录为 BLOCKED，未伪造 PASS。最终合并、Tag 和 Release 仅在 PR 最终 CI 继续全绿后执行。
