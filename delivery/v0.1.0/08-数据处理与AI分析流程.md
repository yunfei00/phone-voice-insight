# Phone Voice Insight V0.1.0 数据处理与 AI 分析流程

## 1. 数据流程

```text
公开入口验证
→ 全量初始化 / 增量采集
→ ReviewRecord 原始记录
→ 确定性规则治理 ReviewQuality
→ AI 复核 GovernanceAIReview
→ ACCEPTED 语料
→ StructuredAnalysis / OpinionAspect
→ Dashboard / Issues / AggregateReport
```

## 2. 采集

荣耀采集器只访问允许的 HTTPS 公开页面，低频请求，不持久化 Cookie，不绕过验证码。帖子、普通回复、官方回复和楼中楼通过稳定 external ID 及 parent_external_id 关联。

## 3. 治理

治理不改写原始内容，输出标准化文本、产品相关性、内容目的、排除原因、质量分和 AI 语料。已处理记录默认跳过；失败重试只处理失败 ID。

`source_id=null` 表示对指定产品不限制来源，与省略该字段语义一致。

## 4. AI

规则治理后，AI 复核只接受明确证据；REJECTED、UNCERTAIN、ERROR 不进入明确问题统计。结构化输出通过 JSON Schema、taxonomy 和证据偏移校验后才持久化。

默认自动化关闭。真实请求受批量、并发、超时、重试和每日 Token 预算约束；展示请求不会触发付费调用。

## 5. 统计

驾驶舱按独立反馈去重；同一反馈可进入多个不同问题类别，但总反馈不重复。发布时间缺失时才使用采集时间回退，并在口径中说明。所有问题支持回查原始记录和来源链接。
