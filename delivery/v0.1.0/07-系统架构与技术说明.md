# Phone Voice Insight V0.1.0 系统架构与技术说明

## 1. 架构

```text
Vue 3 / Element Plus / ECharts
              │ REST / Session
Django REST Framework ─ PostgreSQL
              │
            Redis
              │
      Celery Worker + Beat
              │
荣耀公开采集 / 治理 / AI 结构化 / 报告
```

## 2. 核心模块

- `accounts`：用户、角色、个人 AI 配置和密钥加密。
- `products`：品牌、产品、别名和版本。
- `sources`：来源、采集入口、验证和范围清理审计。
- `collection`：目标控制状态、任务、运行、发现、失败与调度。
- `reviews`：原始反馈、帖子树、规则治理、AI 复核和语料。
- `analysis`：历史分析和 V1 结构化 Schema/证据结果。
- `reports`：驾驶舱聚合、问题洞察、日报/周报和运行监控。

## 3. 数据安全

- 数据库迁移前向兼容，不清空 Volume。
- 原始记录与治理/分析结果分层保存，可追溯。
- 来源入口验证包含 SSRF 防护。
- 管理操作由后端权限控制，不依赖隐藏菜单。
- AI 密钥加密保存，API 不回传明文。
- 测试默认不访问外站、不调用付费 AI。

## 4. 后台任务

Celery 负责采集、治理、AI 结构化和报告调度。任务记录持久化到 PostgreSQL，Redis 只作为 Broker/结果后端；Worker 重启不会删除已持久化业务结果。

## 5. 可观测性

健康接口分别检查 Backend、数据库和 Redis；运行监控区分服务在线、数据更新和 AI 自动化状态。容器健康不等同于业务自动化已启用。
