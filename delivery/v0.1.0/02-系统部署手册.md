# Phone Voice Insight V0.1.0 系统部署手册

## 1. 环境要求

- Linux 服务器或支持 Docker Desktop 的开发机
- Docker Engine 及 Compose V2
- 至少 4 GB 可用内存、10 GB 可用磁盘
- 可访问 PostgreSQL/Redis 镜像和 Python/Node 依赖源

## 2. 配置

从 `.env.example` 创建 `.env`，至少替换：

- `SECRET_KEY`
- `POSTGRES_PASSWORD`
- `ALLOWED_HOSTS`
- `CSRF_TRUSTED_ORIGINS`

AI 密钥只写入受权限保护的服务器环境或用户 AI 配置，不写入仓库。默认保持 `AI_AUTOMATION_ENABLED=false`。

## 3. 首次部署

```bash
git fetch origin --tags
git checkout v0.1.0
docker compose --env-file .env -f docker-compose.prod.yml config --quiet
docker compose --env-file .env -f docker-compose.prod.yml up -d --build
docker compose --env-file .env -f docker-compose.prod.yml ps
```

Backend 启动时自动执行向前兼容迁移及 `collectstatic`。不得删除数据库卷解决迁移问题。

## 4. 升级

1. 检查活动采集/治理/AI 任务。
2. 备份 PostgreSQL 与 `.env`。
3. 拉取 Tag 并验证 `docker compose config --quiet`。
4. 执行 `up -d --build`。
5. 检查六个服务、迁移和健康接口。

## 5. 健康检查

```bash
docker compose -f docker-compose.prod.yml ps
curl -fsS http://127.0.0.1:8088/phone/healthz
curl -fsS http://127.0.0.1:8088/phone/api/v1/health/
docker compose -f docker-compose.prod.yml exec -T celery-worker celery -A config inspect ping
```

预期服务：`postgres`、`redis`、`backend`、`frontend`、`celery-worker`、`celery-beat`。

## 6. 回滚

```bash
git checkout <previous-tag-or-commit>
docker compose --env-file .env -f docker-compose.prod.yml up -d --build
```

数据库迁移均按兼容升级设计。若必须回退数据库，先停止写入并使用部署前备份恢复；禁止直接删除生产 Volume。
