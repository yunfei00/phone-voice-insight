## 已知偏差

- 数据只来自荣耀俱乐部 Power2 话题入口，不代表全体购买用户，也不等同于电商订单评价。
- 10 页上限实际只得到 97 个相关主题和 487 条记录，略低于目标下界；为遵守访问限制没有继续抓取 39 页。
- 低信息、宣传和产品相关性仍是确定性高置信度规则，可能漏掉未见过的俚语、隐性宣传或上下文依赖表达；前端和 Admin 保留人工覆盖。
- 明显页面噪声在固定样本中只有 5 条，虽然本次全部识别正确，样本量仍较小。
- 本报告只评价数据可分析性，不包含情感、续航、发热、问题聚类、口碑结论或产品评分。
