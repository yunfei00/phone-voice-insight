## 2. 本轮完成范围

### 2.1 手机与入口管理

- 新增幂等命令 `python manage.py ensure_honor_power_products`。
- 保留并规范化“荣耀 Power2”，按需创建“荣耀 Power”，统一关联荣耀品牌。
- 名称使用 NFKC、空白和大小写规范化，避免同名产品重复。
- 两个入口分别绑定正确产品、数据来源和话题 ID。
- Power / Power2 使用最长别名优先和同品牌兄弟产品排除规则，避免交叉归类。
- 产品页面支持配置、编辑、打开、验证入口和查看验证结果。

### 2.2 入口验证与安全

- 验证 URL 格式、HTTPS、允许域名、DNS、连接、HTTP 状态、危险重定向、登录/验证码/错误页、帖子列表、帖子 ID、话题身份和产品一致性。
- 拒绝私有、回环、链路本地等非公网解析结果；限制跳转、超时和响应体大小。
- Honor HTTP 客户端使用 `trust_env=False`，不继承系统代理；响应流式限长 2 MiB。
- URL 变更后自动使原验证和 FULL 基线失效；活动任务期间禁止修改入口。
- 生产验证使用公开匿名 HTML，不保存 Cookie、不绕验证码、不使用代理池或私有 API。

### 2.3 智能采集

- 新增 `start_smart_collection(source_target_id)`。
- 无入口、未验证、验证已因 URL 变化失效时拒绝启动，并返回中文原因。
- 有活动任务时幂等返回现有任务，不重复创建。
- 无已验证基线时选择 FULL；有已验证基线时选择 INCREMENTAL。
- 可恢复的失败 FULL 复用检查点和发现记录；不可恢复时重新建立基线。
- 任务创建后真实提交 Celery；提交失败会将任务标记失败、释放目标状态并记录明确错误。
- 管理员才可执行历史任务强制重试和过期任务恢复；普通用户界面隐藏诊断型“采集任务”菜单。

### 2.4 产品采集控制中心

- 手机产品页集中显示入口状态、验证状态、基线状态、当前任务、最近任务、计数、完成时间和错误原因。
- 采集中按现有轮询机制刷新，不引入 WebSocket。
- 没有可靠总数时不显示虚假百分比，只展示可信阶段、检查点和计数。
- “已有历史数据但新版 FULL 未验证”的目标显示“需要恢复”，不会因为有限增量成功误显示为完整采集成功。
- 支持跳转到按产品和入口筛选的原始数据页。

### 2.5 安全清理

- 新增管理员专用的清理预览和执行接口。
- 强制确认文本 `DELETE <source_target_id>`。
- 清理前检查数据库活动任务、来源租约、Celery 活动任务和 AI 分析任务。
- 事务内仅清理指定入口的原始数据及相关治理、分析、任务和检查点；保留产品、入口和定时配置。
- 清理后重置 FULL 基线，下一次智能采集自动选择 FULL。
- 独立审计表记录操作人、时间、入口快照、删除数量、结果和错误；入口删除后审计仍保留。

### 2.6 发布时间与地域

- 明确区分 `published_at` 和 `collected_at`，不再以采集时间冒充发布时间。

## 5. 智能采集失败根因与修复

### 5.1 已确认根因

1. Honor 响应限长实现最初保留了源站压缩头，重建响应后产生二次解压问题，表现为 `HTTP_ERROR`。已改为流式读取解码后内容，并去除不再适用的 `Content-Encoding` / `Content-Length`。
2. 匿名公开话题页面没有旧选择器预期的 `.section-name`，但公开脚本元数据包含 `wxtitle`。入口身份验证现使用页面可见结构并以 `wxtitle` 为安全回退。
3. Power2 历史 FULL 实际扫描话题页 `89/89`，发现 850 个帖子，详情成功 848 个，最终 2 个源帖返回 HTTP 200 的“提示信息”阻断页：`30417234`、`29949239`。严格完整性校验正确拒绝将该次运行标记为完整成功。

### 5.2 修复前后对比

- 修复前：有效公开页面可能因响应重建或话题身份选择器缺失而被判为入口异常。
- 修复后：Power2 和 Power 两个真实公开入口均通过生产验证；仍然不可访问的单帖不会被伪装成成功，FULL 会保留已采数据并明确报告 unresolved 项。

- 荣耀源站已失效或返回“提示信息”的历史帖子无法通过合规公开匿名访问恢复；需要源站恢复或把经业务确认的“永久不可用帖”设计为可审计的豁免规则，不能直接改为 SUCCESS。

- 生产完整 FULL 可能持续较长时间，应继续使用现有分阶段、检查点、失败重试和严格 verification，不建议为赶验收放宽完整性规则。
