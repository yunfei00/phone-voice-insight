# 路线图

## Phase 1：基础框架

Monorepo、Django/Vue、数据服务、任务队列、基础模型、API/Admin、契约、测试、CI、Compose 和文档。

## Phase 2：荣耀俱乐部采集 PoC

已完成：单入口低频帖子/回复采集、官方/版主/达人识别、父子关系、checkpoint、去重、脱敏 fixtures、Celery/API 和前端闭环；本地 2 页/20 帖门禁及重复运行已通过。

## Phase 3：京东采集 PoC

代码与离线契约已完成：商品/接口门禁、评价/追评、来源 SKU 映射、分页、checkpoint、去重、隐私最小化、API/前端与测试。2026-08-08 正常页面出现京东登录墙，真实商品/店铺/接口验证和真实数据序列被合规停止，因此 Phase 3 的真实验收尚未完成。

## Phase 4：数据清洗与治理

下一阶段候选。必须先由人工确认真实京东样本；确认前不启动 AI。内容规范化、垃圾/物流识别、个人信息脱敏、数据质量度量、重放和人工复核工具。

## Phase 5：AI 结构化分析

接入可配置模型，执行严格 Schema、证据验证、版本管理、批处理和人工评估，不直接上线评分。

## Phase 6：问题聚类与统计

在评估通过的数据上实现问题归并、去重、维度/情感趋势和置信区间，明确样本偏差。

## Phase 7：正式看板

提供筛选、趋势、问题排行、证据钻取、质量提示和导出，并完善性能、权限与审计。

## Phase 8：AI 问答与报告

基于可追溯证据实现 RAG 问答、周期报告和引用，答案必须可回到原始反馈，低证据时拒答。
