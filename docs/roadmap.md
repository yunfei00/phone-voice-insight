# 路线图

## Phase 1：基础框架

Monorepo、Django/Vue、数据服务、任务队列、基础模型、API/Admin、契约、测试、CI、Compose 和文档。

## Phase 2：荣耀俱乐部采集 PoC

确认合规边界；实现单入口低频帖子/回复采集、官方标记、分页、checkpoint、去重和脱敏样本契约测试。

## Phase 3：京东采集 PoC

确认公开评价规则；实现单个自营 SKU 的评价/追评、版本映射、分页、checkpoint 和去重。

## Phase 4：数据清洗与治理

内容规范化、垃圾/物流识别、个人信息脱敏、数据质量度量、重放和人工复核工具。

## Phase 5：AI 结构化分析

接入可配置模型，执行严格 Schema、证据验证、版本管理、批处理和人工评估，不直接上线评分。

## Phase 6：问题聚类与统计

在评估通过的数据上实现问题归并、去重、维度/情感趋势和置信区间，明确样本偏差。

## Phase 7：正式看板

提供筛选、趋势、问题排行、证据钻取、质量提示和导出，并完善性能、权限与审计。

## Phase 8：AI 问答与报告

基于可追溯证据实现 RAG 问答、周期报告和引用，答案必须可回到原始反馈，低证据时拒答。
