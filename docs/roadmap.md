# 路线图

## Phase 1：基础框架

Monorepo、Django/Vue、数据服务、任务队列、基础模型、API/Admin、契约、测试、CI、Compose 和文档。

## Phase 2：荣耀俱乐部采集 PoC

已完成：单入口低频帖子/回复采集、官方/版主/达人识别、父子关系、checkpoint、去重、脱敏 fixtures、Celery/API 和前端闭环；本地 2 页/20 帖门禁及重复运行已通过。

## Phase 3：京东采集 PoC（POSTPONED）

代码与离线契约已完成并保留，供未来扩展。2026-08-08 Phase 3.1 独立可视 Chrome 探测出现登录和访问限制，369 条脱敏响应索引中有 70 条 HTTP 403，且没有确认到评价接口；结果分类为 C。由于当前没有稳定且无需规避访问控制的评价入口，Phase 3 正式暂缓，不视为系统缺陷，也不视为已完成。

## Phase 4：荣耀俱乐部数据治理与样本扩容（COMPLETED）

第一版正式数据源只依赖荣耀俱乐部。已完成事实层之上的确定性治理结果、AI 语料层、人工复核、增量采集和数据质量报告；本阶段未调用 AI。

## Phase 5：AI 结构化分析

接入可配置模型，执行严格 Schema、证据验证、版本管理、批处理和人工评估，不直接上线评分。

## Phase 6：问题聚类与统计

在评估通过的数据上实现问题归并、去重、维度/情感趋势和置信区间，明确样本偏差。

## Phase 7：正式看板

提供筛选、趋势、问题排行、证据钻取、质量提示和导出，并完善性能、权限与审计。

## Phase 8：AI 问答与报告

基于可追溯证据实现 RAG 问答、周期报告和引用，答案必须可回到原始反馈，低证据时拒答。
