# 测试方案

自动测试覆盖：15 域标签树、28 组契约正反例、Unicode 证据偏移、PII、标签父子关系、成功持久化、多观点基础结构、幂等、并发唯一约束、显式重分析留史、非法 JSON 有限重试、Provider 超时、低置信度转复核、人工校正留史、确定性聚合、dry-run 不调用模型、API 空/错误状态和路由。

执行命令：

```bash
cd backend
uv run ruff format --check . ../collectors ../ai ../tools
uv run ruff check . ../collectors ../ai ../tools
uv run mypy . ../collectors ../ai ../tools
uv run python manage.py makemigrations --check --dry-run
uv run pytest

cd ../frontend
npm ci
npm run lint
npm run typecheck
npm run test
npm run build
```

真实 AI 测试必须显式关闭 dry-run 并设置低预算。Mock 只验证工程流程，不代表模型准确率。
