# 部署与回滚

## 预发布步骤

1. 备份 PostgreSQL，确认当前 main 与迁移历史。
2. 部署代码后执行 `uv run python manage.py migrate`；迁移仅新增字段和表。
3. 重启 backend、Celery worker 和 frontend，检查 health、taxonomy、quality API。
4. 先创建 dry-run，核对筛选和预算；再以少量内容、低预算显式执行真实模型验收。
5. 不自动回填全部历史数据。

## 回滚

先回滚应用镜像。由于旧代码忽略新增表/字段，可保留数据库新增结构以避免丢失复核和运行历史；若必须回退迁移，应先导出新增四表并确认没有生产结果，再按 Django migration 逆向回退。API Key 不随代码或数据库分析结果迁移。
