# 标签体系 V1.0

机器字典位于 `ai/taxonomy/structured_analysis_v1.json`，版本固定为 `1.0.0`。包含 BAT、PERF、THERM、DISP、CAM、NET、SYS、HW、AI、SEC、ECO、VALUE、SERVICE、NEED、OTHER 十五个一级域及其二级标签。

每个节点包含编码、父编码、名称、定义、正反例、易混淆标签、启用状态和版本。加载器拒绝重复编码、超过两级、错误父子关系、未知混淆标签和版本不一致。正式编码不得原地改义；变更应新增 taxonomy 版本。

查询接口：`GET /api/v1/taxonomies/`。V1 仅提供只读定义，不提供在线修改，以免无审计地改变统计口径。
